지입관리 1차 사용방법
====================

업데이트
--------
설정 탭의 '업데이트 확인' 버튼으로 최신 버전을 확인합니다.
새 버전 설치 전 데이터는 자동 백업되며, 설치 후 프로그램이 다시 실행됩니다.

1. 지입관리.exe를 실행합니다.
2. 설정 탭에서 회사정보와 기본 부과금액을 저장합니다.
3. 차주·차량 탭에서 차주를 먼저 등록한 뒤 차량을 등록합니다.
4. 부과·청구 탭에서 부과월을 입력하고 '월 부과 생성'을 누릅니다.
5. 청구 건을 선택해 청구서를 인쇄하거나 수납을 등록합니다.

데이터 위치
------------
%LocalAppData%\JieipManager\data.json

백업
----
- 저장할 때마다 backup 폴더에 최근 60개를 보관합니다.
- 설정의 '외부 백업 폴더'에 시놀로지 동기화 폴더를 지정하면 하루 1개의 백업이 추가로 저장됩니다.

주의
----
- 1차 테스트 버전입니다. 실제 업무 적용 전 샘플 차주·차량으로 먼저 확인하세요.
- Windows SmartScreen이 표시되면 '추가 정보' -> '실행'을 선택하세요.
- 세금계산서 실제 발행은 2차에서 정식 API 연동 후 사용합니다.
