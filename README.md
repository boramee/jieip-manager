# 지입관리 1차

현재 버전: **1.0.0**

사원 1명이 한 대의 Windows PC에서 사용하는 로컬 업무 프로그램입니다.

## 포함 기능

- 차주·차량 등록, 수정, 종료 관리
- 지입관리비·공과금·보험료·협회비·기타비용 월 일괄 부과
- 부분 수납, 완납, 미수금 및 연체금 계산
- 차주별 청구서 HTML 출력 및 인쇄
- 월 부과 CSV 내보내기
- 검사·보험 만료 일정 및 보험처리·대폐차·세무지원 업무 관리
- 로컬 데이터 자동 저장 및 최근 60개 백업
- 외부 폴더(시놀로지 동기화 폴더 등) 일별 백업

## 업데이트

- `설정` 탭에서 **업데이트 확인**을 누릅니다.
- GitHub 최신 Release가 현재 버전보다 높으면 변경 사항을 표시합니다.
- 설치를 선택하면 데이터를 백업한 뒤 새 EXE로 교체하고 자동 재실행합니다.
- Release 파일명은 반드시 `JieipManager-win-x64.exe`여야 합니다.
- 프로젝트 버전을 올린 뒤 `v1.0.1` 같은 태그를 push하면 GitHub Actions가 Release를 생성합니다.

## 데이터 위치

`%LocalAppData%\JieipManager\data.json`

## 실행

압축을 풀고 `지입관리.exe`를 실행합니다. 첫 실행 시 Windows가 게시자를 확인할 수 없다는 안내를 표시할 수 있습니다.

## 2차 예정

- 실제 회사 청구서 양식 적용
- 전자세금계산서 ASP API 연동
- 은행 입금내역 자동 매칭
- 엑셀 기존자료 일괄 가져오기
- 차량·차주별 첨부문서 관리
